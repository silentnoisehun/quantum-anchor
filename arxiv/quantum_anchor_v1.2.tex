\begin{abstract}
We present Quantum Anchor V1.2 (Tesseract Anchor), a post-pulse experimental protocol for coherent state anchoring on superconducting quantum processors. The original pulse-level protocol (\texttt{qiskit.pulse}, \texttt{meas\_level=0}) was deprecated by IBM in 2025. V1.2 migrates to working APIs and reports evidence grades honestly. We report hardware measurements on IBM \texttt{ibm\_marrakesh} (156Q Heron r2) and on IQM Resonance Garnet 20Q. On IBM we measure single-qubit dynamics $\psi(37\text{ns}) = 0.331662$ under a $\gamma=0$ model, and we show that both the $\gamma=0$ baseline (89.72\% balance) and the $\gamma=0.5$ anchor-on condition (87.74\%) yield \textbf{0\% clear}. On IQM we measure four independent Bell pairs at 95--96\% per-plane balance using a virtual Z rotation of $0.4398$ rad. We \textbf{retract} an earlier positive result that we show to be a circuit tautology. The global 8-qubit correlation was 11.62\%, consistent with statistically independent planes, so the 20-reality synchronized-selection claim is \textbf{not demonstrated}. The physical anchor-drive compensation effect is \textbf{not proven by any measurement in this work}; pulse-level access required to test it was measured to be unavailable on our IQM account tier.
\end{abstract}

\section{Introduction}

The Quantum Anchor hypothesis: a weak, non-destructive pulse acts as an ``anchor'' -- one mode survives the pulse and this survival carries significance. The original V1.0 protocol required pulse-level access (\texttt{qiskit.pulse}, \texttt{meas\_level=0}) which IBM removed from production QPUs in 2025 Q1.

This paper documents:
\begin{enumerate}
\item Five blockers (F1--F5) preventing the original protocol
\item Migration to working APIs: fractional gates + \texttt{qiskit-dynamics} (IBM), circuit-level + raw shot memory (IQM)
\item Hardware measurements with honest evidence grades
\item Tesseract architecture: 4 planes $\times$ 5 realities = 20 pre-realities
\item Retraction of a tautological false positive
\end{enumerate}

\section{The Five Blockers (F1--F5)}

\begin{description}
\item[F1] \texttt{qiskit.pulse} module removed from Qiskit 2.x (2025 Q1).
\item[F2] \texttt{SamplerV2}/\texttt{EstimatorV2} primitives lack \texttt{meas\_level}/\texttt{meas\_return}.
\item[F3] $\text{amp}=0.08 \times 37\text{ns} = 2.96\text{ rad} = 94.2\%$ of $\pi$-pulse -- contradicts ``non-destructive'' claim.
\item[F4] $\gamma=0$ not physically reachable (finite T1/T2).
\item[F5] Raw IQ (\texttt{meas\_level=0}) is discriminator output; final \texttt{meas\_level=2} collapses to bits.
\end{description}

\textbf{Interpretation.} The $\gamma=0$ and $\gamma=0.5$ anchor rows are the
central negative result: \textbf{0\% clear in both conditions}, so no anchor
compensation was observed. The 96.43\% Borg figure and its 100\% clear reading
are \textbf{retracted}: the $\gamma=0$ circuit reversed its own rotations, so
state preservation was a tautology of the circuit construction rather than a
measured property. The Matryoshka decay (97.4\% $\to$ 89.4\%) is cumulative
noise from fractional gate depth, and the ``preserved'' criterion evaluated to
False. $\psi(37\text{ns})$ is a fit under a $\gamma=0$ model that real qubits
cannot satisfy (F4).

\section{Retraction: False Positive}

\subsection{Previous Claim}
``100\% clear at $\gamma=0$ vs 18.8\% at $\gamma=0.5$ = anchor proven''

\subsection{Why Wrong}
The $\gamma=0$ circuit applied \textbf{exact reversal} of rotations (identity operation). The $\gamma=0.5$ circuit did not. This is a tautology: a circuit reversing its own rotations preserves state. The trivial Bloch model predicts this exactly.

\subsection{Corrected Circuit}
\begin{itemize}
\item Always applies damping ($\gamma$-dependent Z-rotations)
\item Anchor drive: optional resonant fractional CRX counteracting damping
\item $\gamma=0$: no damping, no anchor (ideal reference)
\item $\gamma>0$, anchor OFF: damping, coherence decays
\item $\gamma>0$, anchor ON: damping + anchor drive $\to$ prediction: slower decay
\end{itemize}

\subsection{Corrected Results}
Both $\gamma=0$ (89.72\%) and $\gamma=0.5$+anchor (87.74\%) show 0\% clear -- dissipative noise dominates.

\section{IQM Resonance Measurement}

\subsection{Scope of this measurement}

This is a \textbf{circuit-level} measurement. The returned data are classical
bitstrings, \emph{not} analog IQ vectors; this is not $\texttt{meas\_level=0}$.
The $\texttt{rz}(\theta)$ gate is a \textbf{virtual Z rotation} applied in
software: it sends no physical pulse and drives no nonlinear effect. The value
$\phi = 0.4398$ rad is a \emph{parameter} of that rotation, not a frequency that
was ever applied to the device.

\paragraph{Count discrepancy.} 1024 shots were requested but the returned
counts sum to 1016. The tabulated percentages use a 1024 denominator; with the
true denominator the global balance is 11.71\%. We report both and flag the
discrepancy rather than silently adopting either value.

\paragraph{What the per-plane result shows.} Four Bell pairs execute correctly
on Garnet at transpiled depth 4, and the virtual Z rotation did not break them.
A clean Bell pair is the least demanding configuration on a superconducting
QPU, so a high balance is the expected outcome of any working entangling gate.
No $\texttt{rz}$-free control row was measured in this run, so the contribution
of $\texttt{rz}(\phi)$ cannot be separated from the Bell circuit's intrinsic
quality.

\paragraph{What the global result shows.} At 11.62\% the four planes behave as
statistically independent, which is exactly what four separate Bell pairs on
separate qubits produce. This circuit therefore cannot demonstrate the
20-reality synchronized selection.

\subsection{Blocked: pulse-level access}

A pulse-level Sweep job built with all five required \texttt{SweepDefinition}
fields was rejected by the server with
\emph{``Personal account does not have pulse-level access enabled required to
submit this job''}. The client, the 82 exposed channels, and the playlist
structure were all validated; the refusal is an account entitlement, not a
client error. No offline change can circumvent it.

\section{Next Steps}

\begin{enumerate}
\item \textbf{Bell control matrix (free, runnable now).} Measure four rows
      --- \texttt{zero}, \texttt{h}, \texttt{bell} (no $\texttt{rz}$), and
      \texttt{anchor} (with $\texttt{rz}(\phi)$) --- on IQM Starter credits.
      If the last two agree, as physics predicts, the high balance is not an
      anchor effect. This converts the present ambiguity into a documented
      negative result.
\item \textbf{Pulse-level Sweep API --- BLOCKED.} Requires an IQM account
      entitlement absent from the free Starter tier (measured; see above).
\item \textbf{Direct $T_{\text{annihil}}$ measurement} --- blocked on the same
      entitlement.
\item \textbf{Paid QPU routes} (Braket on Rigetti Ankaa-3) are documented but
      deliberately not pursued.
\end{enumerate}
